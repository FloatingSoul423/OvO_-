架构约定
五层为采集、处理、存储、服务、展现。七类逻辑服务为采集、ETL、检索、门户与认领、统计、认证、管理后台。
初期服务层五个 API 模块共同部署于 ECS；采集与 ETL 采用独立 Worker。
RDS 保存事实、认领/授权、持久任务、同事务发件箱和统计汇总；OBS 保存原始快照及受控材料；CSS 只存生效且可公开字段。
检索从 CSS 取得候选后依赖 RDS 权威事实复核可见性与版本（D9）；统计读取 RDS（D4）。
灰色虚线 D1–D9 为 UML 依赖：箭头指向被依赖的提供方。
蓝色实线 F1–F7 为业务数据流：箭头指向数据接收方，不把同方向的数据流冒充 UML 依赖。
客户端仅经服务 HTTPS API；材料访问由服务鉴权。事实、任务状态与 Outbox 在同一个 RDS 事务中提交，投影按版本幂等处理。
