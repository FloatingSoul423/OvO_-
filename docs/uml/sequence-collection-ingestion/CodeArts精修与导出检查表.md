## 必须保留的组合片段

- `alt`：来源未登记/停用/越界 与 校验通过。
- `loop`：按批次和安全检查点读取。
- `alt`：来源失败 与 成功取得记录。
- `alt`：稳定标识匹配、冲突候选、新实体。
- `alt`：完成、人工停止、失败后重试。

## 提交前检查

- [ ] 消息方向和先后顺序与 PlantUML 预览一致。
- [ ] 不跨成果类型自动合并；标题相似不直接合并。
- [ ] 人工确认字段不会被自动更新覆盖。
- [ ] 来源、来源 ID、采集/导入时间、更新时间和使用范围可追踪。
- [ ] 状态只使用待执行、运行中、成功、失败、重试、已停止。
- [ ] 来源失败保留历史、失败范围和检查点；重试保持幂等。
- [ ] 图中未加入数据库表、REST URL、技术框架或未批准架构。
