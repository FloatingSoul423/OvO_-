## 模型范围

主流程覆盖：来源与权限校验、任务由待执行进入运行中、按检查点批量采集、保留来源证据与原始值、字段清洗、同类型去重、创建或关联成果实体、更新检查点、完成后传播到详情/门户/检索/统计。

关键分支覆盖：

1. 来源未登记、停用或超出许可范围时拒绝创建任务；
2. 来源超时、限流或错误时记录失败范围和安全检查点，保留已成功历史；
3. 缺少稳定标识或存在冲突时进入人工核验队列，不直接自动合并；
4. 人工确认字段受保护，自动更新冲突进入待办；
5. 停止任务保留处理历史；失败后从检查点重试，重复输入不重复入库；
6. 更新视图尚未完全同步时如实返回未同步状态。
