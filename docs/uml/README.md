## 文件与工具

- 图源使用 PlantUML `.puml`，导出 SVG，必要时导出 PNG；
- 各模块图和导出文件放在同一主题目录，导出图进入 `generated/`；
- 课程提交时另保留 CodeArts Modeling 源文件和导出图；
- PlantUML 与 CodeArts 两套图必须使用相同术语、状态、守卫条件和业务规则；
- 不提交截图拼贴代替图源。

认领申请状态与学者门户“未认领/已认领”状态属于不同业务对象，不得混成一个状态机。
