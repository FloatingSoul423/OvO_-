# 学术成果分享平台接口设计说明书

03组 可御风雪可燃冰｜作业5构件设计｜V0.1 初稿｜2026-11-18

编写：宋显涵委托 Codex 辅助起草，尚未与其他成员的作业5成果比对；两小组成员、具体分工与签认待填写。本稿定义供原型与未来实现核对的 REST 契约。伴随文件 `07-OpenAPI文档-可御风雪可燃冰.json` 是机器可读合同；文中示例仅为设计，不表示接口已经上线。

## 1 设计依据与边界

依据 SRS FR01—FR16、IN01、业务规则及架构 ADR-01—04。API 由 ECS 模块化业务入口提供；RDS 是事实与权限的权威库，CSS 只给公开候选，OBS 只存原始批次和受控材料，worker 异步执行采集与投影。接口不提供全文托管、收费源采集或成果投稿。

## 2 通用 REST 约定

根路径 `/api/v1`，资源名使用小写复数和连字符；`GET` 只读，`POST` 创建或触发动作，`PATCH` 对部分字段更新。JSON 请求和响应均为 UTF-8。客户端在创建采集任务、提交认领申请和审核决定时携带 `Idempotency-Key`；服务器按账号、路径和键保存结果，重复请求返回原结果，不重复创建或重复授权。列表采用 `limit` 与 `cursor`，默认 20、上限 100；稳定排序与筛选条件绑定，游标失效返回 400 并要求重新查询。时间为 ISO 8601 UTC，ID 为不含个人语义的稳定字符串。

公开 GET 无需登录；认领申请须登录；管理员端需相应能力；门户修改还需目标对象授权。授权由服务端每次校验，不能仅凭 UI 按钮。会话方案在架构落地时确定，本合同用 Bearer 访问令牌描述传输；令牌不得放 URL、日志或错误消息。HTTPS 是部署前置条件。

成功返回资源对象或 `{items,nextCursor}`；创建返回 201 和 `Location`；异步创建采集任务返回 202、任务 ID 和状态查询地址。错误统一为 `{error:{code,message,details,requestId}}`，`message` 可读且不泄露内部证据。400 输入无效，401 未登录，403 无权，404 对象不存在或不可见，409 状态/版本冲突，422 业务校验失败，429 限速，503 检索或依赖暂不可用；内部异常 500。CSS 故障必须返回 503，不允许伪装为结果为空。

## 3 核心接口清单

以下清单覆盖课程指定的检索、门户、认领、采集与统计接口，并补足成果详情及 IN01 合作网络。完整字段、参数和错误响应以同版 OpenAPI JSON 为准。

- 成果检索：`GET /api/v1/search/works`；关键词、类型、年份、领域、机构、数据性质、排序和游标；返回公开结果与分面，CSS 候选须经 RDS 复核。对应 FR01、检索页。
- 成果详情：`GET /api/v1/works/{workId}`；返回四类成果公共与专属字段、公开来源摘要。对应 FR02/FR16、详情页。
- 学者门户：`GET /api/v1/scholars/{scholarId}`；返回公开身份、分类成果和确认状态。对应 FR03、门户页。
- 认领提交：`POST /api/v1/claims`；登录用户提交目标、声明及受控证明引用，返回 201 和申请编号。对应 FR05、申请页。
- 申请进度：`GET /api/v1/claims/{claimId}`；仅申请人或相应审核员可读。对应 FR05、申请页。
- 待审队列：`GET /api/v1/admin/claims`；审核管理员按状态和游标查看，不在列表暴露证明原文。对应 FR05/FR14、审核页。
- 审核决定：`POST /api/v1/admin/claims/{claimId}/decision`；动作、原因和期望版本；通过时事务性授权与审计。对应 FR05、审核页。
- 采集任务提交：`POST /api/v1/admin/collection-tasks`；管理员给出来源、方式和范围，返回 202、任务号及查询地址。对应 FR08、任务管理页。
- 采集任务进度：`GET /api/v1/admin/collection-tasks/{taskId}`；返回状态、处理量、检查点摘要及失败原因。对应 FR08、任务管理页。
- 任务动作：`POST /api/v1/admin/collection-tasks/{taskId}/actions`；`start/stop/retry` 与期望版本；非法迁移返回 409。对应 FR08、任务管理页。
- 统计分布：`GET /api/v1/statistics/works`；按类型、领域、年份和数据性质查询去重数量及更新时间。对应 FR11/FR13。
- 合作网络：`GET /api/v1/scholars/{scholarId}/collaboration-network`；返回公开论文构成的无向边及证据。对应 FR12/IN01。
- 最短合作路径：`GET /api/v1/collaboration-path`；按起点、终点和范围返回逐跳论文证据。对应 IN01。

## 4 关键请求与响应语义

### 4.1 检索

年份两端包含；`type` 只接受 `paper/patent/project/award`；`dataNature` 默认 `real`，显式传 `all` 才包含模拟/混合。领域父节点在服务端展开为下级。查询返回每项当前公开版本与来源摘要；当 CSS 候选版本与 RDS 不一致时剔除该项，并继续在合理候选窗口内补足页面。总量属于检索候选口径，若复核后不精确须标记 `totalRelation=estimated`。无结果返回 200 空列表与原因 `empty`；依赖失败返回 503。

### 4.2 认领

申请中 `evidenceObjectKeys` 是经受控上传流程签发的短期引用，不允许客户端任意传 OBS 地址。证据上传本身的端点与凭据方案待安全评审，在本合同中不宣称可直接访问 OBS。创建时校验登录账号、目标状态、声明与材料。通过决定须在同一 RDS 事务中更新申请、创建/激活门户授权、追加审计和 Outbox；并发冲突返回 409，不能先返回通过再补授权。申请人的查询响应仅包含本人可见理由，不含其他人的材料。

### 4.3 异步采集任务

`POST` 仅受理并持久化 `pending` 任务，202 返回 `Location`；不在 HTTP 请求内完成采集。任务通过动作端点启动，由 worker 租约领取。进度返回 `processedCount/successCount/failureCount`，当总量未知时 `totalCount=null`、`progressPercent=null`。停止保留已处理记录和检查点；失败/超时记录原因，可按状态图重试。非法状态迁移、过期版本和未获准来源分别返回 409/422。来源限速和重试退避由 worker 执行。

### 4.4 合作网络与路径

只用当前公开论文中有效的学者成果关系构边；同一论文对同一学者对只贡献一次，无向、无自环。领域过滤作用于支撑论文，机构过滤作用于论文发生时双方机构。网络默认上限为 200 节点、1000 边；超限返回 422 并要求收窄，不静默截断。路径采用广度优先搜索、以跳数为长度；等长路径按稳定学者 ID 序列决胜。搜索中断或超限返回“未完成”，不得声称无路径或最短。

## 5 其他构件设计

### 5.1 爬虫调度与访问控制

数据源登记保存 API/获准文件/获准网页类别、许可范围、允许类型、限速和启停状态。调度器只领取 `enabled` 且已验证的来源，按来源令牌桶限速；遇 429/503 使用有上限的指数退避与抖动，尊重来源许可和公开 API 约定。禁止绕过登录、付费墙、验证码或反爬限制；许可不明时暂停采集并人工核验。原始批次先写 OBS 再推进检查点，重复批次按来源 ID 与外部 ID 幂等。超时不推断为来源删除。

### 5.2 增量更新与去重

按来源外部 ID 查 `source_record`，比较来源更新时间和内容哈希：新增进入清洗；未变化只更新检查时间；变更保留源版本差异。来源时间未知时以哈希判断，不用采集时间冒充源更新时间。DOI、专利申请号和项目编号按各自命名空间识别稳定匹配；缺稳定 ID 时只生成候选，人工核验后合并。已人工审核字段受保护。每次生效事实变更与 Outbox 同事务提交，CSS/统计消费按对象版本幂等。

### 5.3 检索排序

候选评分由标题匹配、关键词匹配、摘要匹配和精确标识匹配构成，权重为待样本验证的配置项；不能将来源引用量等未经统一的数据直接当质量分。相同评分按公开时间降序、稳定 ID 升序决胜。`search_after` 游标绑定规范化筛选摘要、排序版本和最后排序键。对 RDS 复核剔除的候选继续补足，避免短页误导；候选窗口耗尽时如实返回不足。

### 5.4 统计分析

以 RDS 已生效、公开、真实的成果实体为默认计数集，同一成果多来源只计一次。机构/领域内同成果最多一次，不同机构/领域的分类合计允许超过总量。机构用成果发生时机构，未知单列。关键词热度为包含该词的去重成果数；并列名次相同。合作边只由公开论文的有效共同作者关系构成，每边可回查论文；最短路径按跳数，无完整搜索时不称“最短”。统计投影可从 RDS 全量重算，页面展示更新时间与范围。

## 6 一致性、验证与未决事项

表1是文档到实现的追踪入口。OpenAPI 的示例均为合成数据，未来 API 实现须按 SRS 的具体 AC 和 NF 测试，不以 schema 校验代替业务验收。

|构件|权威对象/规则|交付验证|
|---|---|---|
|搜索 API|CSS 候选 + RDS `work`/授权复核；ADR-01|旧索引撤销对象不泄露；CSS 故障为 503|
|认领 API|`claim_application`、`portal_grant`、`audit_log`；FR05|审批回滚不授权；并发冲突返回 409|
|采集 API|`data_source`、`collection_task`、OBS；ADR-02|任务重复提交幂等，停止保留检查点|
|统计 API|RDS 事实与汇总投影；ADR-04|重复来源不重复计数，重算与增量一致|

待团队确认：身份令牌与证据上传方案、真实证明保留期、索引分词器可用性、实际评分权重、两小组技术路线对照和共同签认。未执行接口联调、性能测试和安全测试，不能把初稿标为已验收。
