## 1 范围与构件契约

本稿只处理公开或已获准的元数据。RDS 保存权威成果、关系、来源、任务和审计；OBS 保留获准原始批次；CSS 仅保存可公开候选；缓存只加速公开热点。后台 worker 负责长任务和派生投影，API 负责权限校验与当前事实复核。表1汇总四个构件的输入输出与需求来源。

## 2 采集调度与访问控制

### 2.1 执行前置与状态

来源必须登记为公开 API、获准文件或获准网页，记录许可范围、允许成果类型、启停状态和来源级限速。调度器只选择 `enabled=true`、许可未撤销且参数处于许可范围的任务；来源不可用、许可不明或访问被拒时暂停并进入人工处理。任务可为待执行、运行中、成功、失败、已停止或重试中，状态和允许迁移以 SRS 采集状态图为准。创建任务的 HTTP 响应只表示受理，不表示采集完成。

### 2.2 领取、限速与恢复

worker 在 RDS 事务内领取可执行任务并设置租约和版本；租约过期才允许其他 worker 接手。每个来源单独计数和限速，遇来源明确的 `Retry-After` 优先遵守，否则使用有上限的指数退避和随机抖动。任何 401/403/验证码/付费墙响应都停止自动访问并记录原因，不尝试规避。原始响应按来源许可允许的字段写入 OBS，成功登记批次后才推进任务检查点；OBS 写失败则不推进。停止只阻止后续批次，不回滚已经成功提交的历史事实。

### 2.3 验证场景

同一来源外部记录重复执行应只有一条当前来源记录，并可在版本历史中看到实际变更；来源 429 应按源限速重试，401/403 不得继续抓取；worker 在写 OBS 前中断不推进检查点；在 OBS 成功、RDS 提交前中断可重放批次且不重复建成果；停止、失败和重试都显示准确状态及原因。总量未知时 `progressPercent=null`，不显示假百分比。

## 3 增量更新与归并

### 3.1 判定步骤

以 `(source_id, external_id)` 定位当前 `source_record`。若不存在，先保存来源记录并进入清洗；若存在且来源更新时间与内容哈希均未变化，只记检查时间，不重复触发索引/统计；若哈希或有依据的源版本变化，追加 `source_record_history`，保留新旧原始对象键和变化类型。来源未提供更新时间时只用内容哈希判断，不把采集时间冒充来源更新时间。来源删除声明与访问失败分别记录，后者不得推断为撤稿。

清洗先验证类型、标题、来源身份和可定位编号，再规范化标识、日期精度、空白、机构及领域。论文 DOI、专利申请号+国家地区、项目编号+来源作用域是强匹配线索；缺少稳定标识或证据冲突时只生成候选，不按标题直接合并。人工审核字段、争议身份和归属不能被自动更新覆盖。每次生效变更在同一 RDS 事务中写事实、审计与 Outbox；消费者按聚合对象版本幂等刷新 CSS 和统计，旧事件不得覆盖新版本。

### 3.2 结果与异常

处理结果区分 `created / unchanged / changed / needs_review / failed`；`needs_review` 保留来源原文与冲突原因，不进入确定公开关系。原始批次、来源版本、合并决策和目标成果 ID 可双向追溯。重复任务、事件重复或倒序时，成果实体数和关系数保持不变；人工保护冲突被拦截并进入队列；来源 404 只在许可与来源规则明确表明删除时才进入删除/失效候选。

## 4 检索排序与公开复核

CSS 用 `public_work_v1` 和 `public_scholar_v1` 别名分别保存可公开字段。中文分词器选择必须在目标 CSS 实例验证；英文统一小写，DOI 等稳定标识走 keyword 精确匹配。成果检索字段为标题、关键词、摘要及公开标识；学者检索字段为姓名、别名、公开机构和简介。组合筛选取交集，父领域展开下级，年份两端包含。分面按当前条件统计去重实体数，不混入受限记录。

排序配置首先考虑精确标识命中，再考虑标题、关键词、摘要的相关性，具体权重由样例集评测后冻结；同分按公开时间降序和稳定 ID 升序。分页游标携带筛选摘要、排序版本和最后排序键。API 拿到候选 ID/版本后逐项在 RDS 复核公开资格、版本和授权；复核失败剔除并在候选窗口内补足。若索引故障，返回明确的检索不可用错误；若候选不足或游标过期，分别返回短页或重新查询提示，不能误报“0 条”。

表2 检索边界样例

|场景|期望结果|
|---|---|
|索引仍有已撤销成果|RDS 复核后不展示该成果|

## 5 统计分析与合作探索

统计事实集默认取 RDS 当前已生效、公开且性质为真实的成果实体；多来源同实体只计一次。机构或领域内同实体最多一次，但同实体可属于多个机构/领域，因此分类合计可大于全局总量。机构归属采用成果发生时机构，未知单列。关键词热度为包含该词的去重成果文档数，同词在一篇成果中重复只计一次；并列名次相同，样本不足时不发布趋势结论。页面必须显示范围、指标定义和汇总更新时间。

统计 worker 消费 Outbox，按受影响实体和维度重算可重建的 RDS 汇总，记录输入版本；事件重复、倒序和历史纠错都可通过全量重算对账。合作网络只以公开论文中的有效共同作者关系构成无向边，同论文对同一学者对贡献一次，边强度为去重共同论文数，且每条边可回查论文。领域过滤作用于论文领域，机构过滤作用于论文发生时两端机构。两学者最短路径按跳数用广度优先搜索；同长路径按稳定学者 ID 序列决胜，结果逐跳附论文证据。节点/边超限或计算中断时报告未完成，不宣称不存在路径或已求得最短路径。

## 6 核对与未决事项

人工核对清单：来源许可与限速证据、任务状态迁移、重复批次、人工保护字段、可公开索引字段、旧版本复核、统计口径、合作边证据和最短路径边界。目标 MySQL/CSS 环境、分词器、评分权重和并发规模尚未实测，须在实施阶段以合成或获准数据执行验证。两小组实际技术路线与工具差异须由双方按真实过程记录补充，不从本稿推断已经完成交叉评审。
