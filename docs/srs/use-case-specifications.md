# UC-01～UC-15 独立用例规约（V0.2 Draft）

> 上游基线：V1.9｜状态：待组内评审｜范围：外部可观察行为，不包含架构、数据库、接口或实现技术

## 公共约定

- 术语、参与者、BR-01～BR-20 以 [SRS 总入口](OvO-SRS-Draft.md) 为准，本文件不重复定义。
- “系统拒绝”均表示业务数据保持原状，并返回可理解且不泄露受控信息的原因。
- 公开版本、待审版本、认领状态、门户授权和成果关系状态相互独立，不得互相代替。

## UC-01 检索成果与学者

| 项目 | 规约 |
|---|---|
| 对应需求 | FR01（FR01-S01～S06） |
| 主要参与者 | 访客 |
| 前置/触发 | 平台存在公开数据；访客输入关键词或筛选、排序、分页条件并提交。 |
| 成功后置 | 返回去重后的公开结果、总量、分页和口径；不改变业务对象。 |
| 失败后置 | 保持查询条件，返回空结果或错误原因，不伪造匹配项。 |

主流程：1）系统解析关键词和检索范围；2）校验类型、年份、领域、机构和数据性质条件；3）只检索公开有效数据；4）按声明规则去重、排序和分页；5）返回结果及总量，用户可进入成果或学者页面。

备选/异常：无匹配项时返回空结果和调整入口；条件冲突或页码越界时给出可修正提示；依赖不可用时明确标记未完成。适用 BR-01、BR-12、BR-14、BR-17，关联 NF01、NF02、NF04。

## UC-02 查看成果详情与来源

| 项目 | 规约 |
|---|---|
| 对应需求 | FR02、FR16 |
| 主要参与者 | 访客 |
| 前置/触发 | 目标成果存在且允许公开；访客打开成果详情。 |
| 成功后置 | 展示公共字段、类型专属字段、参与关系、来源、更新时间和数据性质。 |
| 失败后置 | 对不存在或不可公开对象返回适当提示，不泄露待审或内部证据。 |

主流程：1）系统定位去重后的成果实体；2）读取当前公开版本；3）按论文、专利、项目或获奖展示专属字段；4）展示全部可公开来源和跨源关系；5）提供学者、机构等导航入口。

备选/异常：字段缺失时显示“未知/来源未提供”；来源暂时不可用时保留历史成果和来源标识；链接失效不应删除成果。适用 BR-01、BR-05、BR-07、BR-17、BR-19，关联 NF01、NF03、NF04、NF06。

## UC-03 查看学者门户

| 项目 | 规约 |
|---|---|
| 对应需求 | FR03 |
| 主要参与者 | 访客；次要参与者：登录用户 |
| 前置/触发 | 学者档案存在且可公开；访客打开门户或筛选成果。 |
| 成功后置 | 展示公开简介、机构、领域、认领状态和分类型成果。 |
| 失败后置 | 不展示受控信息，不改变门户、授权或认领申请状态。 |

主流程：1）系统定位已消歧学者；2）展示当前公开门户信息；3）按成果类型和条件加载已生效关系；4）说明收录范围和关系状态；5）未认领门户向登录用户提供申请入口。

备选/异常：重名候选未确认时不得自动合并；无成果时保留门户并说明当前范围；未登录用户访问认领入口时转入登录流程。适用 BR-01、BR-02、BR-03、BR-05、BR-09、BR-19。

## UC-04 管理账号与访问权限

| 项目 | 规约 |
|---|---|
| 对应需求 | FR04 |
| 主要参与者 | 访客、登录用户；次要参与者：管理员 |
| 前置/触发 | 用户注册、登录、退出或发起受保护操作。 |
| 成功后置 | 建立或终止登录状态；受保护操作同时通过角色和对象级授权。 |
| 失败后置 | 不建立授权，不改变学者档案、门户或成果关系。 |

主流程：1）系统接收账号操作；2）校验输入、账号状态和凭据；3）注册时建立独立账号，登录时建立会话；4）受保护操作再次校验角色与目标对象；5）返回操作结果，退出后会话失效。

备选/异常：账号停用时拒绝登录但不删除档案；凭据错误时不透露账号是否存在；无对象授权时即使角色匹配也拒绝。适用 BR-02、BR-03、BR-18，关联 NF01、NF03、NF06。

## UC-05 提交并跟踪门户认领

| 项目 | 规约 |
|---|---|
| 对应需求 | FR05 |
| 主要参与者 | 登录用户 |
| 前置/触发 | 用户已登录且目标学者档案存在；用户提交或补充认领申请。 |
| 成功后置 | 申请进入待审核/待补充/已通过/已驳回中的合法状态并可查询。 |
| 失败后置 | 不授予门户权限，不公开认领材料。 |

主流程：1）用户选择门户；2）系统检查已有授权和冲突；3）用户提交必要声明与证明；4）系统验证完整性并登记待审核；5）用户查看进度、补充要求和最终原因；6）仅审核通过后建立对象级授权。

备选/异常：材料不足进入待补充；已有管理人时进入冲突核验；重复提交返回现有申请；上传或保存失败时不得产生半完成授权。适用 BR-01、BR-03、BR-04、BR-18、BR-19。

## UC-06 审核门户认领

| 项目 | 规约 |
|---|---|
| 对应需求 | FR05、FR14 |
| 主要参与者 | 管理员；次要参与者：申请人、已有门户管理者 |
| 前置/触发 | 管理员有审核权限，存在待处理或已补充申请。 |
| 成功后置 | 形成通过、待补充或驳回决定；通过时新增目标门户授权并记录审计。 |
| 失败后置 | 原授权和门户公开版本保持不变。 |

主流程：1）管理员打开审核队列；2）系统展示申请、冲突和受控证据；3）管理员核验证据并填写理由；4）系统校验申请当前版本；5）登记决定和审计；6）向申请人反馈状态，必要时建立授权。

备选/异常：证据不足时要求补充；冲突申请不得自动转移授权；并发处理时拒绝覆盖较新决定；管理员无目标权限时拒绝。适用 BR-01、BR-03、BR-04、BR-18、BR-19。

## UC-07 维护学者门户

| 项目 | 规约 |
|---|---|
| 对应需求 | FR06 |
| 主要参与者 | 门户管理者；次要参与者：管理员 |
| 前置/触发 | 用户对目标门户具有有效授权并提交资料或展示设置变更。 |
| 成功后置 | 允许直接生效的字段更新，重要字段经审核后形成新公开版本。 |
| 失败后置 | 当前公开版本不变，提交内容可追踪。 |

主流程：1）系统校验对象级授权；2）展示当前公开值和可维护范围；3）参与者填写修改及原因；4）系统校验格式和版本；5）按字段规则直接生效或建立变更申请；6）返回当前状态和处理记录。

备选/异常：重要字段进入待审；版本已变化时要求刷新；超出授权门户或不可维护字段被拒绝。适用 BR-03、BR-05、BR-18，关联 NF01、NF03、NF05、NF06。

## UC-08 确认、补录与纠正成果

| 项目 | 规约 |
|---|---|
| 对应需求 | FR07、FR15 |
| 主要参与者 | 门户管理者；次要参与者：管理员、系统 |
| 前置/触发 | 用户拥有门户授权；选择候选成果、补录已有成果或提交纠错。 |
| 成功后置 | 关系或变更按规则生效，并保留来源、理由、前后值和操作者。 |
| 失败后置 | 全局成果、他人关系和当前公开版本保持不变。 |

主流程：1）系统校验授权；2）展示成果及关系证据；3）用户选择确认、补录、解除或纠错；4）系统校验稳定标识、重复项和影响范围；5）直接处理安全关系或提交审核；6）生效后传播到检索、门户和统计。

备选/异常：共享成果只解除本学者关系；疑似重复进入候选；重要字段纠正待审核；证据冲突或并发变更时保持原结果。适用 BR-03、BR-05～BR-10、BR-18、BR-19。

## UC-09 管理采集任务

| 项目 | 规约 |
|---|---|
| 对应需求 | FR08、FR10、FR16 |
| 主要参与者 | 管理员；次要参与者：外部数据来源、系统 |
| 前置/触发 | 来源已登记且允许使用；管理员创建、启动、停止或重试任务。 |
| 成功后置 | 任务处于合法状态，处理摘要、失败原因、检查点和历史可查询。 |
| 失败后置 | 已公开历史成果不删除，重复执行不重复创建业务实体。 |

主流程：1）管理员配置来源、类型和范围；2）系统校验权限和来源条件；3）任务由待执行进入运行中；4）系统采集并保留原始值、来源与游标；5）逐项登记成功、候选和异常；6）任务进入成功或失败并显示摘要。

备选/异常：管理员可停止运行中任务；失败任务从检查点重试；来源不可用时进入失败且保留历史；同一输入按幂等规则处理。适用 BR-07、BR-10、BR-11、BR-18。

## UC-10 治理成果与学者关系

| 项目 | 规约 |
|---|---|
| 对应需求 | FR09、FR15 |
| 主要参与者 | 管理员、系统 |
| 前置/触发 | 存在待处理来源记录、去重候选或身份/关系候选。 |
| 成功后置 | 形成新建、合并、拆分、确认、排除或待核验结果，并保留证据链。 |
| 失败后置 | 不覆盖人工确认结果，不丢失来源记录和既有关系。 |

主流程：1）系统规范化稳定标识和字段；2）生成成果或学者候选；3）高置信且规则允许的结果自动处理；4）证据不足项进入治理队列；5）管理员比较证据并决定；6）记录前后值和理由并传播生效结果。

备选/异常：仅标题相似不得直接合并；同名不足以合并学者；误合并支持经审计拆分；版本冲突时拒绝覆盖。适用 BR-07～BR-10、BR-12、BR-18、BR-19。

## UC-11 查看统计与机构排名

| 项目 | 规约 |
|---|---|
| 对应需求 | FR11 |
| 主要参与者 | 访客 |
| 前置/触发 | 存在已生效数据；访客选择成果类型、时间、领域、机构或数据性质。 |
| 成功后置 | 展示分布、分类排名、口径、范围、更新时间和可复核总量。 |
| 失败后置 | 数据不足时不生成误导排名，不改变业务数据。 |

主流程：1）系统校验筛选条件；2）按成果实体去重；3）优先使用成果发生时机构；4）按披露口径聚合和排序；5）显示结果、未知项、数据性质和更新时间。

备选/异常：机构缺失归入未知；并列采用确定性规则；样本不足给出提示；模拟/混合数据明确标识。适用 BR-12、BR-13、BR-14、BR-16、BR-17。

## UC-12 查看专家合作网络

| 项目 | 规约 |
|---|---|
| 对应需求 | FR12 |
| 主要参与者 | 访客 |
| 前置/触发 | 公开论文作者关系已生效；访客选择学者或网络范围。 |
| 成功后置 | 展示可导航的节点、由共同论文支撑的边、强度说明和证据。 |
| 失败后置 | 不把同名或未确认关系纳入网络，不改变关系数据。 |

主流程：1）系统定位已消歧学者；2）按领域、机构等条件筛选公开论文；3）由共同论文生成合作边；4）按声明口径计算强度；5）展示网络和论文证据入口。

备选/异常：网络过大时按确定范围截取并说明；孤立节点仍可展示；论文证据不可公开时不生成对应公开边。适用 BR-09、BR-12、BR-15、BR-16、BR-17。

## UC-13 查看领域热点

| 项目 | 规约 |
|---|---|
| 对应需求 | FR13 |
| 主要参与者 | 访客 |
| 前置/触发 | 领域与时间窗口内存在可统计字段；访客提交分析条件。 |
| 成功后置 | 展示热点排名或趋势、指标解释、范围、更新时间和数据性质。 |
| 失败后置 | 数据不足或字段不可用时给出提示，不生成伪结论。 |

主流程：1）系统校验领域和时间范围；2）筛选已生效成果；3）归一关键词或主题；4）按声明口径聚合并排序；5）展示结果、范围、限制和更新时间。

备选/异常：同义词规则不明确时不静默合并；样本不足时只展示说明；热点不得表述为学术质量认证。适用 BR-12、BR-14、BR-16、BR-17。

## UC-14 管理后台与审计

| 项目 | 规约 |
|---|---|
| 对应需求 | FR14 |
| 主要参与者 | 管理员；次要参与者：系统 |
| 前置/触发 | 管理员已登录并拥有目标管理能力，进入工作台或处理对象。 |
| 成功后置 | 待办、异常、账号、分类、来源和审核操作按权限完成，关键行为可审计。 |
| 失败后置 | 目标业务状态不变，越权和并发失败留下必要记录。 |

主流程：1）系统校验管理员能力；2）汇总有权查看的待办与异常；3）管理员筛选并打开对象；4）系统展示当前状态和证据；5）管理员作出处理并填写原因；6）系统校验版本、更新状态并追加审计。

备选/异常：不同管理能力只展示授权范围；敏感材料最小化显示；并发版本冲突时不覆盖；审计记录不得由普通业务操作删除。适用 BR-01、BR-03～BR-05、BR-18、BR-19。

## UC-15 探索合作关系

| 项目 | 规约 |
|---|---|
| 对应需求 | IN01 |
| 主要参与者 | 访客；次要参与者：系统 |
| 前置/触发 | 两名目标学者公开且已消歧；访客提交起点、终点和可选范围。 |
| 成功后置 | 返回一条确定的最短合作路径，每一跳可追溯到共同论文。 |
| 失败后置 | 无路径或节点异常时给出明确反馈，不影响基础检索和合作网络。 |

主流程：1）系统确认起终点身份；2）按领域、机构等条件构建公开合作图；3）以共同论文关系作为边；4）计算最短路径并按确定规则处理等长结果；5）展示逐跳学者、论文证据、范围和更新时间。

备选/异常：起终点相同返回零跳说明；无路径返回明确结果；节点歧义要求用户选择；计算超出展示范围时返回限制说明。适用 BR-13、BR-15～BR-17、BR-20，关联 NF01、NF02、NF04、NF05。
