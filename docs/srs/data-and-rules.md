# 公共数据与细化规则

本文件只定义业务字段和对外判据，不规定存储结构。V1.9 已规定的语义保持不变；新增操作口径作为 OvO V0.4 的本组细化建议，适用于本版场景走查，须由两组在联合冻结时签认。本文示例数据均为验收夹具，不是已实施调研或实测结果。

## 1 数据对象与字段

| 对象 | 最小输入及字段语义 | 缺失与约束 |
|---|---|---|
| 成果公共字段 | 类型、非空标题、来源身份、来源记录标识或文件内可定位编号、数据性质 | 缺任一项进入异常；内部实体标识由平台赋予，不要求来源提供 |
| 论文 | DOI、作者及顺序、载体、发表日期及精度、摘要、关键词、发表状态 | DOI可缺；此时不凭标题直接合并。引用量按来源分别列出，不相加 |
| 专利 | 申请号及国家或地区、公开号、申请人、发明人、申请日、公开日、授权日、IPC、状态及状态来源日期 | 申请人不等于发明人；同一申请不同公开号保留关联。缺稳定标识转候选 |
| 科研项目 | 项目编号及来源域、负责人、承担单位、类别、起止时间和状态 | 论文基金编号只能作线索，不能产生完整项目；不默认采集经费 |
| 获奖 | 奖项名称、年度、等级、授奖单位、获奖成果、人员或团队 | 获奖人和获奖项目分别表达；未知字段不能用空泛默认值补齐 |
| 学者 | 稳定档案标识、姓名及别名、公开机构和任职时间、外部标识及命名空间、领域 | 同名不等于同人；机构不同也不能单独证明不同人 |
| 学者成果关系 | 学者、成果、角色、顺序、来源、证据、确认状态 | 自动关联、本人确认、待核验、争议、已排除分别表达 |
| 来源记录 | 来源、来源ID、采集或导入时间、来源更新时间、原始允许字段、使用范围、数据性质 | 未提供的来源更新时间标未知，不用采集时间冒充 |
| 认领申请 | 申请人、目标学者、本人声明、必要证明引用、提交时间、申请状态、决定及原因 | 证明私有；普通学者门户字段不得包含证明原文 |
| 变更申请 | 提交人、目标、当前版本、前值、建议值、证据、理由、审核结果 | 当前版本不一致须重新核验；待审值不覆盖公开值 |
| 采集任务 | 来源、方式、范围、输入标识、状态、时间、成功异常失败范围、检查点 | 未知总量不能显示伪造百分比；每次执行保留历史 |
| 审计事件 | 操作者或系统身份、对象、操作、时间、前后值、原因、关联事件 | 不记录密码、凭据和证明原文；普通业务操作不能覆盖审计 |

## 2 字段通用约束

- 不可公开字段直接排除；可公开但未提供的字段标注“未知”或“来源未提供”。二者不能混用。
- 时间保留来源精度和语义：论文发表日期、专利申请日、项目开始时间、获奖年度作为本版类型内年份筛选依据；缺失时不匹配具体年份，统计单列未知。
- 日期必须真实存在，开始时间不得晚于结束时间；只有年份时不补造月日。
- 标识归一必须保留原值。DOI去掉协议前缀和首尾空白并忽略大小写；专利按国家地区及申请号作用域匹配；项目编号按来源或资助机构作用域匹配。
- 关键词去首尾空白；仅纯空白视为空。成果检索范围与学者范围互斥，筛选维度间取交集，年份两端均包含。
- 领域采用本地树；本版选择父领域时包含其下级，页面明确显示。无法映射的来源分类保持“待分类”，不强制对应。

## 3 本版可执行细化口径

### R-PUB 关系公开与计算范围

来源许可允许公开且证据符合已登记归属规则的“自动关联”可以出现在门户，并显示未由本人确认；“本人确认”另行标记。待核验、争议和已排除不作为确定公开归属，也不生成合作边。进入争议后，成果实体本身是否公开独立判断；不能因某个关系争议删除全局成果。

### R-EDIT 门户字段与审核

仅展示顺序、可见分组等不改变事实的展示设置可直接生效。姓名、公开机构、简介、研究领域等事实字段修改进入审核。修改姓名和机构须通过身份核验，不通过普通展示设置修改。共享成果字段、争议归属、解除关系均审核；无冲突的本人确认可直接记录。

### R-UPDATE 来源更新

未人工保护且无冲突的来源描述字段可更新，并保留旧源值。已人工审核值、身份和归属争议进入核验；来源变新不解除人工保护。来源删除声明、撤稿、链接失效分别记录，网络访问失败不能推断其中任一事件。

### R-COUNT 计数与排名

平台总量按成果实体一次计数。每一机构或领域内同实体最多计一次，同成果可计入多个机构和领域，分类合计因此可超过全局总量。机构采用成果发生时单位；缺失归未知。并列数量名次相同，稳定机构标识只用于展示次序。已核实版本关系共用成果实体；未核实候选的统计处理状态必须披露。

真实、模拟、混合互斥：全部来源真实且公开值未混入模拟内容为真实；全部模拟为模拟；其他为混合。默认现实统计排除模拟和混合；演示模式可以包含但须显式说明。性质无法确认时进入治理，不默认标真实。

### R-GRAPH 合作与路径

本期合作边仅以公开论文共同作者为依据，为无向关系。同一论文对同一学者对只贡献一次，强度为去重共同论文数；无自环。专利、项目和获奖不自动成为论文合作证据。

领域筛选作用于支撑边的论文领域；机构筛选作用于该论文发生时两端作者所属单位，两端均需属于所选机构集合。无发生时机构的关系不以现任机构补齐。筛选后保留有证据的边及其端点，查询端点可作为孤立节点保留。

最短按跳数计算，不按强度加权。相同端点为零跳。多条等长路径按学者稳定标识序列字典序选第一条，注明“仅展示一条，不表示唯一”。只在完整声明范围内求得的路径可称该范围最短；超限或中断必须报未完成。

### R-ANALYSIS 热点与展示限制

关键词热度采用“包含该词的去重成果文档数”；同一成果重复出现一个词不重复增加。拉丁词大小写归一，其他同义词只按登记且有版本的词典合并。按频次降序、同频次同名次且词面稳定排序。时间桶无数据与数据缺失分别显示。

本版建议演示默认：网络最多展示200个节点、1000条边；超过范围提示收窄，不静默截断。热点有效样本少于5条时只展示样本数与计数并提示不足，不发布名次或趋势结论。以上为本组可复核展示建议，联合冻结前可调整；调整须更新验收夹具与变更记录。

### R-ACCOUNT 注册与材料约束

本组建议账号标识为4至32个字母、数字或下划线且忽略大小写判重；凭据为12至128个字符，不回显、不截断。格式不是 V1.9 原始条款，联合评审时签认。注册不要求登录、不自动创建学者档案。

认领至少包含目标档案、本人声明和一项可核验的机构任职或公开科研身份依据，不强制身份证。课程演示只使用合成证明；建议限制为PDF/JPEG/PNG、每份不超过10 MiB且最多3份。提交前展示允许类型、大小和数量；不符合时不进入审核。真实性仍需管理员结合公开证据判断。

真实材料保留期限由团队负责人确认，不能由文档编写者代定。本版清理验收使用显式设定期限的合成材料：到期且无未结争议后删除内容，保留对象标识、决定和清理时间等最小审计。真实材料启用前须完成政策签认。

## 4 细化建议与共同基线的关系

R-PUB、身份分离、来源追踪和人工保护直接细化 V1.9 第5章。字段直接生效范围、展示限制、注册限制、机构子图口径及等长路径排序属于本组提出的确定性细化。它们用于让当前SRS可以走查，不代表另一组已同意。联合评审须记录采纳、替代或不采纳；NF02的2秒和NF05的60秒仍为上游明确的待评审目标。
