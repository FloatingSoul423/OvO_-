# 账号 认领与维护 索引

> V0.3：本文件仅登记编号。行为、验收和关联项以详细分册为单一定义。

[完整规格](detailed/02-account-claim-maintenance-detailed.md)

| 编号 | 可观察能力 |
|---|---|
| FR04-S01 | 用户可注册账号；重复标识、无效输入和不完整信息得到明确反馈。 |
| FR04-S02 | 有效账号可登录并退出；失败登录不暴露账号是否存在等不必要信息。 |
| FR04-S03 | 每次受保护操作均校验登录状态、账号状态、角色和对象级授权。 |
| FR04-S04 | 被停用或失效的账号不能继续受保护操作，已有公开档案不因此删除。 |
| FR04-S05 | 越权操作被拒绝并产生可审计的安全事件摘要。 |
| FR05-S01 | 登录用户可选择未认领或需要核验的学者档案并提交认领信息及必要证明。 |
| FR05-S02 | 提交前校验完整性、本人声明和目标档案状态；不合格申请不进入审核。 |
| FR05-S03 | 管理员可查看申请、证据摘要和冲突提示，并作补充、通过或驳回决定。 |
| FR05-S04 | 待补充申请可由申请人补充后重新进入待审核；历史材料和决定保留。 |
| FR05-S05 | 通过后授予目标门户对象级管理权限；驳回后不授予权限并显示原因。 |
| FR05-S06 | 已有管理人的冲突认领保持原授权不变，进入人工争议处理。 |
| FR05-S07 | 申请人可查看本人申请状态、要求补充内容和最终结果。 |
| FR06-S01 | 门户管理者可维护允许修改的简介、公开领域和展示设置。 |
| FR06-S02 | 系统区分可直接生效与须审核的修改；重要公开信息待审期间保留旧版本。 |
| FR06-S03 | 管理者可查看提交状态、审核结果和已生效版本。 |
| FR06-S04 | 所有重要修改保留前后值、操作者、时间、原因和审核结果。 |
| FR06-S05 | 未授权者和被停用账号的修改请求被拒绝。 |
| FR07-S01 | 门户管理者可逐项或批量确认系统为本人生成的候选成果关系。 |
| FR07-S02 | 可补录已存在且可核验的成果元数据及来源，不提供投稿或发表。 |
| FR07-S03 | 可对遗漏、误归属、字段错误或解除本人关联提交纠错申请和依据。 |
| FR07-S04 | 管理员可比较当前公开值、申请值和来源证据，批准或驳回变更。 |
| FR07-S05 | 通过后更新公开关系/字段并传播到门户、检索和统计；待审时不公开。 |
| FR07-S06 | 解除个人关系不删除成果实体、来源记录或其他参与者关系。 |
| FR07-S07 | 申请人可查询每项变更的状态、结果和驳回原因。 |
