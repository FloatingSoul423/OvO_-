# 横切非功能需求（NF01～NF08）

> 状态：V0.1 Draft｜适用于四个功能域；数值型待评审目标不描述为实测结果。

| 编号 | 子需求 | 可测试验收条件 |
| --- | --- | --- |
| NF01-S01 | 访客无需登录即可完成公开检索、详情、门户和统计主流程。 | Given 访客未登录，When 执行公开主流程，Then 不被要求登录；发起受保护操作时才提示登录。 |
| NF01-S02 | 页面区分加载、无结果、失败、权限不足和数据更新中状态。 | Given 五种状态样例，When 分别触发，Then 提示文本与可执行下一步互不混淆。 |
| NF01-S03 | 筛选可清除，表单校验指出具体缺失或非法项，并保留无需重填的合法内容。 | Given 表单一项非法，When 提交，Then 指出该项且其他合法输入仍保留。 |
| NF02-S01 | 待评审性能目标：不少于 1 万条成果、10 个并发查询用户、固定查询集预热后持续 5 分钟，普通检索 P95 不超过 2 秒。 | Given 指标已由团队冻结，When 在记录的环境执行基准，Then 报告数据量、硬件、查询集、并发、错误率和 P95；未测不得宣称通过。 |
| NF02-S02 | 管理后台、统计和网络查询另行记录响应基线，不自动套用普通检索 2 秒目标。 | Given 执行相关测试，When 出具结果，Then 按操作类型分别报告条件和指标。 |
| NF03-S01 | 凭据、认领证明和受控审核材料不得向无权用户展示或写入公开页面。 | Given 普通用户，When 直接访问材料或管理入口，Then 被拒绝且响应不包含材料内容。 |
| NF03-S02 | 受保护操作同时执行角色和对象级授权，前端限制不替代后端判定。 | Given 门户甲管理者，When 修改门户乙或执行管理员操作，Then 被拒绝并记录安全摘要。 |
| NF04-S01 | 外部来源不可用时，已收录公开数据仍可浏览；失败任务可恢复。 | Given 来源中断，When 访问历史成果并重试失败任务，Then 历史数据可见且恢复不重复入库。 |
| NF04-S02 | 项目阶段至少完成一次备份恢复核验并记录范围、时间和结果。 | Given 约定备份样例，When 执行恢复，Then 关键对象数量和关系与备份一致，异常有记录。 |
| NF05-S01 | 待评审一致性目标：审核或更新生效后，正常情况下 60 秒内在详情、门户、检索和统计反映一致结果。 | Given 目标已冻结，When 变更生效，Then 在约定检查点内各视图一致；超时显示未同步或失败状态。 |
| NF05-S02 | 变更、确认、审核、合并和拆分保留可追踪记录。 | Given 任一关键结果，When 查询审计，Then 能定位来源、操作者/系统动作、时间、前后值和原因。 |
| NF06-S01 | 不默认采集或公开手机号、私人邮箱、未公开项目细节和非必要证明信息。 | Given 来源含此类字段，When 导入并公开展示，Then 字段被排除或受控，不出现在访客页面。 |
| NF06-S02 | 审核材料定义访问范围与清理规则；模拟数据显式标识。 | Given 材料超过保留条件或数据为模拟，When 检查，Then 按规则清理/限制并能识别模拟性质。 |
| NF07-S01 | 新增或停用数据来源不得改变用户检索、门户和统计的主要操作语义。 | Given 替换来源，When 执行公开主流程，Then 用户行为和需求结果保持一致，来源差异被标注。 |
| NF07-S02 | 提供配置、运行、故障定位、备份恢复和数据口径说明；实际仓库优先于过时 README。 | Given 新成员按文档操作，When 核对仓库，Then 能定位有效配置和文档；冲突处有版本说明。 |
| NF08-S01 | 后续实现阶段至少 3 个核心模块行覆盖率达到 80%，并含边界、权限和集成测试。 | Given 选定核心模块，When 执行测试，Then 报告模块范围、行覆盖率与失败用例，不以总体平均掩盖单模块不足。 |
| NF08-S02 | CodeArts 中保留规定的需求、代码检查、构建、测试和流水线证据，并维护需求到实现/测试的对应关系。 | Given 进入实现阶段，When 抽查任一核心需求，Then 可追踪到适用 SPEC、任务、变更和测试证据。 |

## 适用说明

- NF02-S01 和 NF05-S01 的数值来自 V1.9 待评审目标，冻结前只能作为测试计划输入。
- O02 若未来实施，必须另行细化行为记录授权、偏好查看和清除；本版不把 O02 作为 Must。
- NF08 的覆盖率和工程流程属于后续实现验收，本轮只建立追踪要求，不声称已经完成。
