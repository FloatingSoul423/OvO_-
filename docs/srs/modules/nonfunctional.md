# 非功能需求 索引

> V0.3：本文件仅登记编号。行为、验收和关联项以详细分册为单一定义。

[完整规格](detailed/nonfunctional-detailed.md)

| 编号 | 可观察能力 |
|---|---|
| NF01-S01 | 访客无需登录即可完成公开检索、详情、门户和统计主流程。 |
| NF01-S02 | 页面区分加载、无结果、失败、权限不足和数据更新中状态。 |
| NF01-S03 | 筛选可清除，表单校验指出具体缺失或非法项，并保留无需重填的合法内容。 |
| NF02-S01 | 待评审性能目标：不少于 1 万条成果、10 个并发查询用户、固定查询集预热后持续 5 分钟，普通检索 P95 不超过 2 秒。 |
| NF02-S02 | 管理后台、统计和网络查询另行记录响应基线，不自动套用普通检索 2 秒目标。 |
| NF03-S01 | 凭据、认领证明和受控审核材料不得向无权用户展示或写入公开页面。 |
| NF03-S02 | 受保护操作同时执行角色和对象级授权，前端限制不替代后端判定。 |
| NF04-S01 | 外部来源不可用时，已收录公开数据仍可浏览；失败任务可恢复。 |
| NF04-S02 | 项目阶段至少完成一次备份恢复核验并记录范围、时间和结果。 |
| NF05-S01 | 待评审一致性目标：审核或更新生效后，正常情况下 60 秒内在详情、门户、检索和统计反映一致结果。 |
| NF05-S02 | 变更、确认、审核、合并和拆分保留可追踪记录。 |
| NF06-S01 | 不默认采集或公开手机号、私人邮箱、未公开项目细节和非必要证明信息。 |
| NF06-S02 | 审核材料定义访问范围与清理规则；模拟数据显式标识。 |
| NF07-S01 | 新增或停用数据来源不得改变用户检索、门户和统计的主要操作语义。 |
| NF07-S02 | 提供配置、运行、故障定位、备份恢复和数据口径说明；实际仓库优先于过时 README。 |
| NF08-S01 | 后续实现阶段至少 3 个核心模块行覆盖率达到 80%，并含边界、权限和集成测试。 |
| NF08-S02 | CodeArts 中保留规定的需求、代码检查、构建、测试和流水线证据，并维护需求到实现/测试的对应关系。 |
