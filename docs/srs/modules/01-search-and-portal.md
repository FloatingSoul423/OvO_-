# 功能域一：检索、成果详情与学者门户（FR01～FR03）

> 状态：V0.1 Draft｜父基线：V1.9｜关联用例：UC-01～UC-03

## FR01 成果与学者检索

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR01-S01 | 访客可输入关键词检索已收录的成果或学者，并明确选择检索对象。 |
| FR01-S02 | 成果结果可按类型、年份范围、研究领域、机构和真实/模拟标识筛选。 |
| FR01-S03 | 多个筛选条件可组合使用，用户可逐项或全部清除筛选。 |
| FR01-S04 | 结果支持明确的排序方式和稳定分页；切页时保留查询条件。 |
| FR01-S05 | 结果项可进入成果详情或学者门户，并保留返回查询上下文。 |
| FR01-S06 | 无结果、条件无效和查询失败分别给出可区分反馈。 |

### 参与者与条件

- **主要参与者：** 访客；**相关参与者：** 无。
- **前置条件：** 平台已有可公开检索的数据；无需登录。
- **触发条件：** 访客提交关键词或筛选条件。
- **成功后置：** 返回与当前条件一致的结果集、总量、排序和分页信息。

### 主成功流程

1. 访客选择“成果”或“学者”检索范围并输入关键词；关键词可为空，但至少应存在一个有效筛选条件。
2. 系统校验年份范围、筛选值和分页参数；合法后执行查询。
3. 系统按当前范围返回结果总量、当前页数据、排序方式和已生效筛选条件。
4. 成果结果展示标题、类型、时间、主要参与者、机构及来源/数据性质摘要；学者结果展示姓名、机构、领域和门户认领状态摘要。
5. 访客可调整条件、排序、分页，或进入详情/门户；返回时原查询上下文仍可恢复。

### 备选与异常流程

- **A1 无关键词：** 存在有效筛选时允许浏览；关键词和筛选均为空时提示输入条件，不提交无边界查询。
- **A2 无结果：** 显示“未找到匹配结果”和当前条件，提供清除/调整筛选入口，不伪造推荐结果。
- **E1 条件无效：** 起始年份大于结束年份、页码越界或筛选值失效时拒绝查询并指出具体条件。
- **E2 查询失败：** 显示查询失败和可重试入口，不把失败显示成零结果，不暴露内部异常信息。

### 权限与业务规则

- 公开检索不要求登录；仅返回符合 BR-01 的公开版本。
- 执行 BR-12、BR-14、BR-17；同一成果的多个来源不得形成重复结果。
- 默认排序及相关性判定由检索 SPEC 细化，但必须确定、可解释且在相同条件下保持稳定。

### 验收条件

- **AC-FR01-S01-01：** Given 平台存在标题含“知识图谱”的公开成果，When 访客在成果范围检索该词，Then 返回匹配成果且不混入仅匹配姓名的学者结果。
- **AC-FR01-S02-01：** Given 数据覆盖多种类型和年份，When 组合选择“专利＋2024～2026＋机构甲”，Then 每条结果均满足全部条件。
- **AC-FR01-S04-01：** Given 结果超过一页，When 用户切换页码后返回上一页，Then 查询条件、排序和页码可恢复且同一实体不因来源重复出现。
- **AC-FR01-S06-01：** Given 查询服务失败，When 用户提交合法条件，Then 页面显示失败和重试提示，而不是“0 条结果”。

## FR02 成果详情与来源访问

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR02-S01 | 展示标题、类型、参与者、机构、时间、领域、状态和更新时间等公共字段。 |
| FR02-S02 | 按论文、专利、项目、获奖展示适用的类型专属字段。 |
| FR02-S03 | 展示全部已保留来源及来源标识，区分来源事实与人工修正。 |
| FR02-S04 | 参与者和机构存在平台页面时可导航，缺失关联时不生成虚假链接。 |
| FR02-S05 | 有可用原站地址时提供跳转；不承诺全文、付费内容或原站可用性。 |
| FR02-S06 | 展示预印本/正式发表等已核实状态和版本关系；未知时明确标记未知。 |
| FR02-S07 | 缺失字段、已知失效链接和不可公开字段采用明确占位或省略规则。 |

### 参与者与条件

- **主要参与者：** 访客；**前置条件：** 目标成果存在且公开可见。
- **触发条件：** 访客从检索、门户或直接入口打开成果详情。
- **成功后置：** 访客能够识别成果类型、参与关系、来源、更新时间和数据性质。

### 主成功流程

1. 系统定位目标成果实体并读取当前公开版本。
2. 系统展示公共字段，再按成果类型展示专属字段：论文的载体/DOI/发表状态，专利的申请号/公开号/IPC，项目的编号/负责人/周期，获奖的奖项/年度/等级/授奖单位。
3. 系统展示参与者角色与顺序、关联机构、领域及可导航对象。
4. 系统列出数据来源、来源标识、采集或导入时间、最近更新时间及真实/模拟标识。
5. 存在经核验的版本关系或原站链接时展示相应入口。

### 备选与异常流程

- **A1 字段缺失：** 标记“未知/来源未提供”，不得推测补全。
- **A2 多来源冲突：** 显示当前公开值并保留可见的来源说明；冲突证据进入治理流程，访客不可访问内部审核材料。
- **E1 成果不存在或不可公开：** 返回明确提示，不泄露待审或已限制对象的字段。
- **E2 外链已知失效：** 禁用入口或提示已知不可用；未经过检测的原站故障不宣称由平台控制。

### 权限与业务规则

- 执行 BR-01、BR-05、BR-07、BR-17、BR-19。
- 平台审核通过不等于论文已同行评审或研究结论可信。
- 详情页不提供本平台全文托管、付费下载或投稿入口。

### 验收条件

- **AC-FR02-S02-01：** Given 四类成果样例，When 分别打开详情，Then 公共字段一致且每类只展示适用专属字段，不混用专利申请人与发明人。
- **AC-FR02-S03-01：** Given 一个成果合并两个来源，When 查看详情，Then 只展示一个成果实体并可查看两个来源及更新时间。
- **AC-FR02-S05-01：** Given 成果无全文链接，When 查看详情，Then 不显示“下载全文”承诺，并仍可查看元数据来源。
- **AC-FR02-S07-01：** Given 来源未提供日期，When 查看详情，Then 显示未知或不展示该值，不使用当前日期替代。

## FR03 学者门户浏览

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR03-S01 | 展示学者姓名/别名、公开机构、研究领域、简介和门户认领状态。 |
| FR03-S02 | 按论文、专利、项目、获奖分类展示已收录且可公开的成果。 |
| FR03-S03 | 门户和成果详情支持相互导航，并保留参与角色信息。 |
| FR03-S04 | 未认领门户仍可访问，但明确标示“未认领/未由本人确认”。 |
| FR03-S05 | 页面说明数据收录范围、更新时间、归属/确认状态和真实/模拟性质。 |
| FR03-S06 | 成果较多时支持类型、年份等门户内筛选和稳定分页。 |

### 参与者与条件

- **主要参与者：** 访客；**前置条件：** 学者档案存在且未被限制公开。
- **触发条件：** 访客从搜索结果、成果参与者或直接入口打开门户。
- **成功后置：** 展示该档案当前公开信息及按规则关联的成果，不暗示穷尽全球成果。

### 主成功流程

1. 系统展示学者基本信息、别名、公开机构与领域。
2. 系统显示门户认领状态、数据更新时间和收录范围说明。
3. 系统按四类成果分组展示关联成果，并标示自动关联、本人确认或待核验等允许公开的关系状态。
4. 访客可筛选成果、进入成果详情，或从成果返回门户。
5. 对未认领门户，系统提供认领入口但不因此限制公开浏览。

### 备选与异常流程

- **A1 无已收录成果：** 仍展示档案与“暂无已收录成果”，不删除门户。
- **A2 存在待审变更：** 继续展示当前公开版本，不向访客展示待审内容。
- **E1 档案被合并或更正：** 若存在有效替代档案则提供明确跳转；否则提示不可用。

### 权限与业务规则

- 执行 BR-01～BR-03、BR-05、BR-09、BR-19。
- “已认领”只表示管理授权，不代表全部成果已由本人确认。
- 私人邮箱、手机号、审核证明和未公开项目细节不在门户公开。

### 验收条件

- **AC-FR03-S02-01：** Given 门户关联四类成果，When 访客查看门户，Then 成果按类型可区分并能进入正确详情页。
- **AC-FR03-S04-01：** Given 学者档案尚未被认领，When 访客打开门户，Then 门户可浏览且明确标示未认领。
- **AC-FR03-S05-01：** Given 门户含自动关联和本人确认成果，When 查看列表，Then 两类关系状态可区分且页面说明收录范围。
- **AC-FR03-S06-01：** Given 门户成果超过一页，When 按年份筛选并翻页，Then 所有结果满足条件且无重复实体。
