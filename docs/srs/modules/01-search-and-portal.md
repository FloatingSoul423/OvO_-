# 检索 成果详情与学者门户 索引

> V0.4：本文件仅登记编号。行为、验收和关联项以详细分册为单一定义。

[完整规格](detailed/01-search-and-portal-detailed.md)

| 编号 | 可观察能力 |
|---|---|
| FR01-S01 | 访客可输入关键词检索已收录的成果或学者，并明确选择检索对象。 |
| FR01-S02 | 成果结果可按类型、年份范围、研究领域、机构和真实/模拟标识筛选。 |
| FR01-S03 | 多个筛选条件可组合使用，用户可逐项或全部清除筛选。 |
| FR01-S04 | 结果支持明确的排序方式和稳定分页；切页时保留查询条件。 |
| FR01-S05 | 结果项可进入成果详情或学者门户，并保留返回查询上下文。 |
| FR01-S06 | 无结果、条件无效和查询失败分别给出可区分反馈。 |
| FR02-S01 | 展示标题、类型、参与者、机构、时间、领域、状态和更新时间等公共字段。 |
| FR02-S02 | 按论文、专利、项目、获奖展示适用的类型专属字段。 |
| FR02-S03 | 展示全部已保留来源及来源标识，区分来源事实与人工修正。 |
| FR02-S04 | 参与者和机构存在平台页面时可导航，缺失关联时不生成虚假链接。 |
| FR02-S05 | 有可用原站地址时提供跳转；不承诺全文、付费内容或原站可用性。 |
| FR02-S06 | 展示预印本/正式发表等已核实状态和版本关系；未知时明确标记未知。 |
| FR02-S07 | 缺失字段、已知失效链接和不可公开字段采用明确占位或省略规则。 |
| FR03-S01 | 展示学者姓名/别名、公开机构、研究领域、简介和门户认领状态。 |
| FR03-S02 | 按论文、专利、项目、获奖分类展示已收录且可公开的成果。 |
| FR03-S03 | 门户和成果详情支持相互导航，并保留参与角色信息。 |
| FR03-S04 | 未认领门户仍可访问，但明确标示“未认领/未由本人确认”。 |
| FR03-S05 | 页面说明数据收录范围、更新时间、归属/确认状态和真实/模拟性质。 |
| FR03-S06 | 成果较多时支持类型、年份等门户内筛选和稳定分页。 |
