# 详细规格五：非功能需求

> 状态：V0.2 Draft｜生成依据：V1.9、模块概览和公共规则｜所有条目须经人工评审后冻结

## 公共说明

本分册逐条采用统一 SRS 模板。为避免重复，术语、参与者定义、BR-01～BR-20 和 UC 注册表以 `../../OvO-SRS-Draft.md` 为公共真源；每条仍显式给出适用角色、条件、流程、数据、状态、权限、规则、验收与关联项。实现技术不属于本分册。

本分册共包含 **17** 条子需求。

## NF01-S01 访客无需登录即可完成公开检索、详情、门户和统计主流程

- **父需求/优先级：** NF01 / Non-functional
- **主要/相关参与者：** 访客及所有交互角色 / 系统

### 规格字段

| 字段 | 规格 |
|---|---|
| 需求描述 | 系统应满足以下要求：访客无需登录即可完成公开检索、详情、门户和统计主流程；遵守本分册公共上下文和 BR-01、BR-03，不得通过未声明的实现假设改变需求语义。 |
| 前置条件 | 适用功能可访问；适用规则、公开范围和当前版本可识别。 |
| 触发条件 | 用户执行公开或受保护交互，且本条能力被调用。 |
| 输入/业务数据 | 交互步骤、状态和表单输入；当前对象版本、数据公开范围和适用规则版本。 |
| 输出/可观察结果 | 可理解、可继续操作的反馈；失败、无结果、待处理或权限不足须与成功明确区分。 |
| 状态变化 | 不规定业务状态变化；无状态变化时保持原状态，不创建伪状态。 |
| 权限规则 | 受保护操作仍须鉴权；界面隐藏不替代角色和对象级鉴权。 |
| 业务规则 | BR-01、BR-03；冲突时进入评审，不在本条私自重定义。 |
| 备选流程 | A1：环境或样例不满足前置条件时结论记为未执行/不可判定，不记为通过。 A2：仅部分场景通过时分别记录，不用平均结果掩盖失败项。 |
| 异常流程 | E1：输入无效、对象不存在或状态不允许时拒绝操作，指出可修正原因。 E2：依赖失败或处理超时时返回失败/未完成状态，不伪装成无结果或成功。 E3：并发版本已变化时不覆盖新结果，要求刷新后重新判断。 |

### 主成功流程

1. 评审人员准备与“访客无需登录即可完成公开检索、详情、门户和统计主流程”对应的可复现实验或检查样例。
2. 记录前置环境、数据范围、角色、操作步骤和预期结果。
3. 执行“访客无需登录即可完成公开检索、详情、门户和统计主流程”验证，采集可观察结果和失败证据。
4. 将实际结果与验收条件比较，不以未执行或局部结果代替通过。
5. 保存结论、限制和需要改进的事项。

### 验收条件

- AC-NF01-S01-01：Given 适用功能可访问，When 访客及所有交互角色执行本条操作，Then 可观察结果必须满足“访客无需登录即可完成公开检索、详情、门户和统计主流程”，并返回“可理解、可继续操作的反馈”中与本条相关的结果；不满足该行为即判定失败。
