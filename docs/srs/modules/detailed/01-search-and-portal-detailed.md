# 详细规格一：检索、成果详情与学者门户

> 状态：V0.2 Draft｜生成依据：V1.9、模块概览和公共规则｜所有条目须经人工评审后冻结

## 公共说明

本分册逐条采用统一 SRS 模板。为避免重复，术语、参与者定义、BR-01～BR-20 和 UC 注册表以 `../../OvO-SRS-Draft.md` 为公共真源；每条仍显式给出适用角色、条件、流程、数据、状态、权限、规则、验收与关联项。实现技术不属于本分册。

本分册共包含 **19** 条子需求。

## FR01-S01 访客可输入关键词检索已收录的成果或学者，并明确选择检索对象

- **父需求/优先级：** FR01 / Must
- **主要/相关参与者：** 访客 / 无

### 规格字段

| 字段 | 规格 |
|---|---|
| 需求描述 | 系统应满足以下要求：访客可输入关键词检索已收录的成果或学者，并明确选择检索对象；遵守本分册公共上下文和 BR-01、BR-12、BR-14、BR-17，不得通过未声明的实现假设改变需求语义。 |
| 前置条件 | 平台存在可公开检索的数据；查询条件可被解析；适用规则、公开范围和当前版本可识别。 |
| 触发条件 | 访客提交关键词、筛选、排序或分页操作，且本条能力被调用。 |
| 输入/业务数据 | 关键词、检索范围、类型、年份、领域、机构、数据性质、排序及分页；当前对象版本、数据公开范围和适用规则版本。 |
| 输出/可观察结果 | 与条件一致的去重结果、总量、分页和明确反馈；失败、无结果、待处理或权限不足须与成功明确区分。 |
| 状态变化 | 不改变业务对象状态；无状态变化时保持原状态，不创建伪状态。 |
| 权限规则 | 公开能力无需登录；只返回公开版本；界面隐藏不替代角色和对象级鉴权。 |
| 业务规则 | BR-01、BR-12、BR-14、BR-17；冲突时进入评审，不在本条私自重定义。 |
| 备选流程 | A1：没有匹配数据时返回空结果及调整条件入口，不把空结果描述为系统失败。 A2：部分字段未知时显示未知/来源未提供，不推测补全。 |
| 异常流程 | E1：输入无效、对象不存在或状态不允许时拒绝操作，指出可修正原因。 E2：依赖失败或处理超时时返回失败/未完成状态，不伪装成无结果或成功。 E3：并发版本已变化时不覆盖新结果，要求刷新后重新判断。 |

### 主成功流程

1. 参与者进入对应功能并提出“访客可输入关键词检索已收录的成果或学者，并明确选择检索对象”请求。
2. 系统校验目标对象的公开状态与输入条件。
3. 系统依据适用业务规则读取当前有效数据，执行“访客可输入关键词检索已收录的成果或学者，并明确选择检索对象”。
4. 系统对结果去重并附带必要的范围、状态或来源说明。
5. 系统返回可观察结果；无匹配数据时进入备选流程。

### 验收条件

- AC-FR01-S01-02：Given 平台存在可公开检索的数据，When 访客执行本条操作，Then 可观察结果必须满足“访客可输入关键词检索已收录的成果或学者，并明确选择检索对象”，并返回“与条件一致的去重结果、总量、分页和明确反馈”中与本条相关的结果；不满足该行为即判定失败。
- AC-FR01-S01-03：Given 目标数据不存在、不可公开或输入边界无效，When 执行“访客可输入关键词检索已收录的成果或学者，并明确选择检索对象”，Then 系统应给出明确反馈且不得泄露受控信息或伪造结果。

### 关联项

- **用例：** UC-01；**非功能需求：** NF01、NF02、NF04；**数据对象：** Achievement、Scholar、Organization、Field；**关联图：** DGM-USECASE-01（图模任务完成后核对）。
