# 详细规格四：统计、管理与合作探索

> 状态：V0.2 Draft｜生成依据：V1.9、模块概览和公共规则｜所有条目须经人工评审后冻结

## 公共说明

本分册逐条采用统一 SRS 模板。为避免重复，术语、参与者定义、BR-01～BR-20 和 UC 注册表以 `../../OvO-SRS-Draft.md` 为公共真源；每条仍显式给出适用角色、条件、流程、数据、状态、权限、规则、验收与关联项。实现技术不属于本分册。

本分册共包含 **30** 条子需求。

## FR11-S01 展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径

- **父需求/优先级：** FR11 / Must
- **主要/相关参与者：** 访客 / 系统

### 规格字段

| 字段 | 规格 |
|---|---|
| 需求描述 | 系统应满足以下要求：展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径；遵守本分册公共上下文和 BR-12、BR-13、BR-14、BR-16、BR-17，不得通过未声明的实现假设改变需求语义。 |
| 前置条件 | 存在已生效且满足统计条件的数据；统计口径可披露；适用规则、公开范围和当前版本可识别。 |
| 触发条件 | 访客选择统计主题、范围或筛选条件，且本条能力被调用。 |
| 输入/业务数据 | 成果类型、年份、领域、机构、数据性质、统计版本和筛选条件；当前对象版本、数据公开范围和适用规则版本。 |
| 输出/可观察结果 | 分布、机构分类排名、口径、更新时间和可复核范围；失败、无结果、待处理或权限不足须与成功明确区分。 |
| 状态变化 | 不改变业务对象；统计版本可由旧版更新为新版；无状态变化时保持原状态，不创建伪状态。 |
| 权限规则 | 公开统计只使用允许公开且满足口径的数据；界面隐藏不替代角色和对象级鉴权。 |
| 业务规则 | BR-12、BR-13、BR-14、BR-16、BR-17；冲突时进入评审，不在本条私自重定义。 |
| 备选流程 | A1：样本不足时显示不足说明和当前范围，不生成误导性排名或路径。 A2：存在多种展示结果时采用已声明的确定规则，并允许收窄范围。 |
| 异常流程 | E1：输入无效、对象不存在或状态不允许时拒绝操作，指出可修正原因。 E2：依赖失败或处理超时时返回失败/未完成状态，不伪装成无结果或成功。 E3：并发版本已变化时不覆盖新结果，要求刷新后重新判断。 |

### 主成功流程

1. 参与者选择分析对象和范围，发起“展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径”。
2. 系统校验范围、时间窗口、数据性质和统计版本。
3. 系统按已声明口径筛选已生效数据并执行聚合或关系计算。
4. 系统生成“展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径”结果，同时附带口径、范围、更新时间和证据入口。
5. 参与者查看结果或调整条件重新计算。

### 验收条件

- AC-FR11-S01-02：Given 存在已生效且满足统计条件的数据，When 访客执行本条操作，Then 可观察结果必须满足“展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径”，并返回“分布、机构分类排名、口径、更新时间和可复核范围”中与本条相关的结果；不满足该行为即判定失败。

### 关联项

- **用例：** UC-11；**非功能需求：** NF01、NF02、NF04、NF05；**数据对象：** Achievement、Organization、Field、MetricSnapshot；**关联图：** DGM-USECASE-01（图模任务完成后核对）。
