# 详细规格三：采集、治理、更新与追踪

> 状态：V0.2 Draft｜生成依据：V1.9、模块概览和公共规则｜所有条目须经人工评审后冻结

## 公共说明

本分册逐条采用统一 SRS 模板。为避免重复，术语、参与者定义、BR-01～BR-20 和 UC 注册表以 `../../OvO-SRS-Draft.md` 为公共真源；每条仍显式给出适用角色、条件、流程、数据、状态、权限、规则、验收与关联项。实现技术不属于本分册。

本分册共包含 **34** 条子需求。

## FR08-S01 管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态

- **父需求/优先级：** FR08 / Must
- **主要/相关参与者：** 管理员 / 外部数据来源、系统

### 规格字段

| 字段 | 规格 |
|---|---|
| 需求描述 | 系统应满足以下要求：管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态；遵守本分册公共上下文和 BR-07、BR-11、BR-18，不得通过未声明的实现假设改变需求语义。 |
| 前置条件 | 来源已登记且使用条件允许；管理员具备采集权限；适用规则、公开范围和当前版本可识别。 |
| 触发条件 | 管理员创建、启动、停止或重试采集任务，且本条能力被调用。 |
| 输入/业务数据 | 来源、数据类型、采集范围、输入标识、调度参数和任务控制命令；当前对象版本、数据公开范围和适用规则版本。 |
| 输出/可观察结果 | 任务状态、进度、处理摘要、失败原因和历史记录；失败、无结果、待处理或权限不足须与成功明确区分。 |
| 状态变化 | 任务在待执行、运行中、成功、失败、重试、已停止间合法转移；无状态变化时保持原状态，不创建伪状态。 |
| 权限规则 | 只有采集管理员可控制任务；不得绕过来源访问控制；界面隐藏不替代角色和对象级鉴权。 |
| 业务规则 | BR-07、BR-11、BR-18；冲突时进入评审，不在本条私自重定义。 |
| 备选流程 | A1：证据不足或存在冲突时进入候选/异常队列，不强制自动决定。 A2：重复输入按幂等规则处理，保留本次任务记录但不重复创建业务实体。 |
| 异常流程 | E1：输入无效、对象不存在或状态不允许时拒绝操作，指出可修正原因。 E2：依赖失败或处理超时时返回失败/未完成状态，不伪装成无结果或成功。 E3：并发版本已变化时不覆盖新结果，要求刷新后重新判断。 E4：权限不足时拒绝操作，业务数据保持不变，并记录必要的安全或审计摘要。 |

### 主成功流程

1. 管理员或系统发起“管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态”。
2. 系统检查来源条件、权限、输入标识和当前处理状态。
3. 系统校验输入并保留原始值、来源和处理上下文。
4. 系统按照业务规则执行“管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态”，区分成功、候选、异常或失败。
5. 系统保存结果、证据链和可恢复信息，必要时更新业务状态。
6. 系统返回处理摘要；管理员可定位失败或待核验项。

### 验收条件

- AC-FR08-S01-01：Given 来源已登记且使用条件允许，When 管理员执行本条操作，Then 可观察结果必须满足“管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态”，并返回“任务状态、进度、处理摘要、失败原因和历史记录”中与本条相关的结果；不满足该行为即判定失败。

### 关联项

- **用例：** UC-09；**非功能需求：** NF03、NF04、NF07；**数据对象：** DataSource、CollectionTask、SourceRecord、AuditLog；**关联图：** DGM-USECASE-01、DGM-STATE-01（图模任务完成后核对）。
