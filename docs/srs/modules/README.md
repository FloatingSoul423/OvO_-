# 模块 SRS

本目录按实际分工保存成员负责的模块 SRS。确定负责人后再创建模块文件，避免空占位文档造成“已经完成”的误判。

建议文件名：

- `search-portal.md`：FR01～FR03；
- `account-claim-maintenance.md`：FR04～FR07；
- `collection-governance.md`：FR08～FR10、FR15～FR16；
- `analytics-admin-innovation.md`：FR11～FR14、IN01；
- `nonfunctional.md`：NF01～NF08。

文件范围可按最终人员分工调整，但 FR/IN/NF 编号必须唯一，不得在多个模块中重新定义不同语义。
