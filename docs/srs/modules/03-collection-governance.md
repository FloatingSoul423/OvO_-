# 采集 治理 更新与追踪 索引

> V0.3：本文件仅登记编号。行为、验收和关联项以详细分册为单一定义。

[完整规格](detailed/03-collection-governance-detailed.md)

| 编号 | 可观察能力 |
|---|---|
| FR08-S01 | 管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态。 |
| FR08-S02 | 管理员可基于公开 API、获准文件或获准网页来源创建采集任务。 |
| FR08-S03 | 任务展示来源、参数摘要、创建/开始/结束时间、进度、处理量和状态。 |
| FR08-S04 | 管理员可在允许状态下启动、停止和重试任务。 |
| FR08-S05 | 失败或停止保留已成功历史数据、失败原因和可恢复上下文。 |
| FR08-S06 | 同一输入重复执行不得产生重复成果，任务历史可追踪。 |
| FR09-S01 | 校验各成果类型的最小必填项，对缺失、非法日期和无效标识分类处理。 |
| FR09-S02 | 规范化标题空白、标识符、日期语义、机构/领域引用等可比较值，同时保留原始值。 |
| FR09-S03 | 优先依据 DOI、申请号、项目编号等稳定标识识别重复。 |
| FR09-S04 | 缺少稳定标识时结合标题、年份、类型和参与者生成候选，不直接合并。 |
| FR09-S05 | 对预印本、修订版和正式发表建立有证据的版本关系，证据不足时保留独立候选。 |
| FR09-S06 | 合并成果时保留全部来源、参与者和冲突字段，不丢失可追溯事实。 |
| FR09-S07 | 不确定、冲突或规则无法处理的记录进入人工核验队列。 |
| FR09-S08 | 管理员可批准合并、拒绝候选或拆分误合并结果，所有决定留痕。 |
| FR10-S01 | 系统按来源标识和已有版本区分新增、未变化、变更和来源删除/失效。 |
| FR10-S02 | 新增记录进入清洗去重；未变化记录只更新时间检查信息。 |
| FR10-S03 | 变更记录保留源版本差异，并按字段规则决定直接更新或进入审核。 |
| FR10-S04 | 自动变更不得覆盖人工确认/审核值；冲突进入处理队列。 |
| FR10-S05 | 更新失败记录原因和处理范围，可从安全检查点恢复。 |
| FR10-S06 | 生效变更传播到详情、门户、检索和统计，并反馈未生效或失败状态。 |
| FR15-S01 | 保存姓名及别名、公开机构、外部标识、领域和合作者等可核验证据。 |
| FR15-S02 | 规范化姓名表达但不因姓名相同自动认定同一学者。 |
| FR15-S03 | 稳定标识或充分一致证据可支持同一身份判定，并记录判定依据。 |
| FR15-S04 | 证据不足或互相矛盾时只生成身份/归属候选并转人工核验。 |
| FR15-S05 | 成果关系保存学者、角色、顺序、来源和确认状态。 |
| FR15-S06 | 管理员可确认、排除、改归属或拆分误合并身份，并保留历史。 |
| FR15-S07 | 认领通过不自动确认全部成果；本人确认不替其他参与者确认。 |
| FR15-S08 | 修正后的关系传播到门户、检索、统计和合作网络。 |
| FR16-S01 | 论文、专利、科研项目、获奖四类成果均可收录、查询和查看。 |
| FR16-S02 | 每类成果保留公共字段及必要专属字段，字段语义不混用。 |
| FR16-S03 | 每条来源记录保留来源、来源 ID、采集/导入时间、更新时间和使用范围说明。 |
| FR16-S04 | 真实、模拟和混合数据显式标识，并支持按数据性质核对数量。 |
| FR16-S05 | 来源暂不可用时历史已收录数据仍可浏览，并显示最后更新时间。 |
| FR16-S06 | 去重后成果总量可复核；课程最终规模目标不少于 1 万条。 |
