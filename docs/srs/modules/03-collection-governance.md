# 功能域三：数据采集、治理、更新、消歧与来源追踪（FR08～FR10、FR15～FR16）

> 状态：V0.1 Draft｜父基线：V1.9｜关联用例：UC-02、UC-08～UC-10

## FR08 数据源接入与采集任务管理

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR08-S01 | 管理员登记经核验/获准的数据来源、使用条件、数据类型和启停状态。 |
| FR08-S02 | 管理员可基于公开 API、获准文件或获准网页来源创建采集任务。 |
| FR08-S03 | 任务展示来源、参数摘要、创建/开始/结束时间、进度、处理量和状态。 |
| FR08-S04 | 管理员可在允许状态下启动、停止和重试任务。 |
| FR08-S05 | 失败或停止保留已成功历史数据、失败原因和可恢复上下文。 |
| FR08-S06 | 同一输入重复执行不得产生重复成果，任务历史可追踪。 |

### 参与者与流程

- **主要参与者：** 管理员；**相关参与者：** 外部数据来源。
- **前置条件：** 来源已登记且使用条件允许；管理员具备采集管理权限。
- **主流程：** 选择来源和范围→校验配置→创建待执行任务→启动为运行中→显示进度→完成后置为成功并输出处理摘要。
- **备选流程：** 运行中可停止并进入已停止；失败任务可发起重试，先进入重试再重新运行。
- **异常流程：** 来源不可用、限流、输入格式不符或权限失效时记录失败原因；不能把部分读取直接标记为完整成功。
- **权限/规则：** BR-07、BR-11、BR-18；不得绕过登录、验证码或访问控制，不复用未授权凭据。

### 验收条件

- **AC-FR08-S02-01：** Given 一个获准文件来源，When 管理员创建任务，Then 任务记录来源、范围和输入标识并进入待执行。
- **AC-FR08-S04-01：** Given 任务运行中，When 管理员停止，Then 状态变为已停止且已成功历史数据仍可查询。
- **AC-FR08-S06-01：** Given 同一输入已成功处理，When 再次执行，Then 不增加重复成果且任务记录仍独立可追踪。

## FR09 数据清洗、规范化与成果去重

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR09-S01 | 校验各成果类型的最小必填项，对缺失、非法日期和无效标识分类处理。 |
| FR09-S02 | 规范化标题空白、标识符、日期语义、机构/领域引用等可比较值，同时保留原始值。 |
| FR09-S03 | 优先依据 DOI、申请号、项目编号等稳定标识识别重复。 |
| FR09-S04 | 缺少稳定标识时结合标题、年份、类型和参与者生成候选，不直接合并。 |
| FR09-S05 | 对预印本、修订版和正式发表建立有证据的版本关系，证据不足时保留独立候选。 |
| FR09-S06 | 合并成果时保留全部来源、参与者和冲突字段，不丢失可追溯事实。 |
| FR09-S07 | 不确定、冲突或规则无法处理的记录进入人工核验队列。 |
| FR09-S08 | 管理员可批准合并、拒绝候选或拆分误合并结果，所有决定留痕。 |

### 参与者与流程

- **参与者：** 系统、管理员；**前置条件：** 存在待处理来源记录。
- **主流程：** 校验最小字段→规范化并保留原值→按稳定标识查重→比较证据→确定新建/合并/版本关联/候选→保存结果及来源链。
- **备选流程：** 稳定标识缺失时只生成候选；明确版本证据建立版本关系而非简单标题合并。
- **异常流程：** 稳定标识冲突、类型矛盾、日期不合理或人工值冲突时进入异常队列，不静默选择任一值。
- **权限/规则：** BR-07、BR-08、BR-10、BR-12、BR-18；标题相似不能独立触发合并。

### 验收条件

- **AC-FR09-S03-01：** Given 两条来源记录的规范化 DOI 相同，When 处理，Then 形成一个成果实体并保留两个出处。
- **AC-FR09-S04-01：** Given 两条无稳定标识记录仅标题相似，When 年份或参与者证据不足，Then 只生成候选而不自动合并。
- **AC-FR09-S05-01：** Given 预印本与正式发表记录有明确版本证据，When 治理完成，Then 保留各自状态和来源并建立关系，不重复计入约定实体总量。
- **AC-FR09-S08-01：** Given 成果被误合并，When 管理员执行拆分，Then 恢复正确实体/来源关系且保留原合并与拆分审计。

## FR10 增量更新与变更处理

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR10-S01 | 系统按来源标识和已有版本区分新增、未变化、变更和来源删除/失效。 |
| FR10-S02 | 新增记录进入清洗去重；未变化记录只更新时间检查信息。 |
| FR10-S03 | 变更记录保留源版本差异，并按字段规则决定直接更新或进入审核。 |
| FR10-S04 | 自动变更不得覆盖人工确认/审核值；冲突进入处理队列。 |
| FR10-S05 | 更新失败记录原因和处理范围，可从安全检查点恢复。 |
| FR10-S06 | 生效变更传播到详情、门户、检索和统计，并反馈未生效或失败状态。 |

### 参与者与流程

- **参与者：** 系统、管理员；**前置条件：** 来源已有历史记录且本次获取结果可识别。
- **主流程：** 比较来源版本→分类新增/未变/变更→处理新增与变更→保护人工值→记录轨迹→发布生效结果→验证关联视图一致。
- **备选流程：** 来源声明删除或撤稿时记录状态，不因一次访问失败直接删除实体；链接失效只改变链接状态。
- **异常流程：** 中途中断可恢复；部分失败须列出成功/失败范围，不把整批标记为全成功。
- **权限/规则：** BR-05、BR-07、BR-10、BR-18；一致性目标遵循 NF05，未冻结前不得声称已达到。

### 验收条件

- **AC-FR10-S01-01：** Given 一条新增、一条未变、一条字段变更记录，When 执行更新，Then 三者被正确分类且轨迹可核对。
- **AC-FR10-S04-01：** Given 来源新值与已审核人工值冲突，When 更新，Then 公开人工值不被覆盖且产生待处理冲突。
- **AC-FR10-S05-01：** Given 更新批次中途失败，When 恢复处理，Then 已成功记录不重复创建，失败部分可继续处理。
- **AC-FR10-S06-01：** Given 变更已批准生效，When 查看详情、门户和统计，Then 均采用同一已生效版本或明确显示同步失败。

## FR15 学者身份消歧与成果归属

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR15-S01 | 保存姓名及别名、公开机构、外部标识、领域和合作者等可核验证据。 |
| FR15-S02 | 规范化姓名表达但不因姓名相同自动认定同一学者。 |
| FR15-S03 | 稳定标识或充分一致证据可支持同一身份判定，并记录判定依据。 |
| FR15-S04 | 证据不足或互相矛盾时只生成身份/归属候选并转人工核验。 |
| FR15-S05 | 成果关系保存学者、角色、顺序、来源和确认状态。 |
| FR15-S06 | 管理员可确认、排除、改归属或拆分误合并身份，并保留历史。 |
| FR15-S07 | 认领通过不自动确认全部成果；本人确认不替其他参与者确认。 |
| FR15-S08 | 修正后的关系传播到门户、检索、统计和合作网络。 |

### 参与者与流程

- **参与者：** 系统、管理员、相关门户管理者；**前置条件：** 存在学者候选或成果参与者记录。
- **主流程：** 收集公开证据→规范化姓名/机构标识→比较稳定标识及多维证据→确定同一/不同/待核验→建立带证据的成果关系→同步已生效结果。
- **备选流程：** 外部标识缺失时综合机构、领域、合作者等证据；证据不充分保持候选，不追求强制自动归属。
- **异常流程：** 稳定标识冲突、同名跨机构不确定、认领人与已有关系冲突时进入人工核验；不得用私人联系方式作为公开消歧证据。
- **权限/规则：** BR-02～BR-06、BR-09、BR-18、BR-19。

### 验收条件

- **AC-FR15-S02-01：** Given 两名同名但证据不同的学者，When 处理，Then 不因姓名相同而合并。
- **AC-FR15-S03-01：** Given 姓名表达不同但稳定标识一致且无冲突，When 核验，Then 可归为同一档案并保存依据。
- **AC-FR15-S07-01：** Given 用户认领门户通过，When 查看该门户候选成果，Then 未确认成果仍保持原关系状态。
- **AC-FR15-S08-01：** Given 管理员修正误归属，When 修正生效，Then 门户、检索、统计和合作网络不再采用错误关系。

## FR16 四类成果覆盖与来源追踪

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR16-S01 | 论文、专利、科研项目、获奖四类成果均可收录、查询和查看。 |
| FR16-S02 | 每类成果保留公共字段及必要专属字段，字段语义不混用。 |
| FR16-S03 | 每条来源记录保留来源、来源 ID、采集/导入时间、更新时间和使用范围说明。 |
| FR16-S04 | 真实、模拟和混合数据显式标识，并支持按数据性质核对数量。 |
| FR16-S05 | 来源暂不可用时历史已收录数据仍可浏览，并显示最后更新时间。 |
| FR16-S06 | 去重后成果总量可复核；课程最终规模目标不少于 1 万条。 |

### 参与者与流程

- **参与者：** 系统、管理员、访客；**前置条件：** 数据来自获准来源或明确标识的课程模拟数据。
- **主流程：** 导入四类记录→按类型校验字段→治理与去重→保留来源链和数据性质→发布可查询样例→汇总去重数量。
- **异常流程：** 字段缺失标记未知；来源临时失败不删除历史；无法判断类型的记录进入异常队列而非错误归类。
- **权限/规则：** BR-07、BR-12、BR-17；项目经费、私人联系方式和未公开细节不默认采集或公开。

### 验收条件

- **AC-FR16-S01-01：** Given 四类数据均已入库，When 分别检索，Then 每类至少存在可打开详情的样例。
- **AC-FR16-S02-01：** Given 专利和项目样例，When 查看详情，Then 发明人/申请人与项目负责人/承担单位字段不混用。
- **AC-FR16-S04-01：** Given 真实与模拟数据并存，When 访客查看或管理员统计，Then 数据性质可识别且数量可分别核对。
- **AC-FR16-S05-01：** Given 外部来源不可用，When 访客查看已收录成果，Then 历史元数据仍可浏览并显示来源与最后更新时间。
