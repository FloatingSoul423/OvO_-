# 功能域四：统计分析、管理后台与合作探索（FR11～FR14、IN01）

> 状态：V0.1 Draft｜父基线：V1.9｜关联用例：UC-11～UC-15

## FR11 成果统计与机构分类排名

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR11-S01 | 展示成果类型、年份和领域分布，并披露数据/时间范围与计数口径。 |
| FR11-S02 | 提供机构成果分类排名，支持成果类型、年份和领域筛选。 |
| FR11-S03 | 同一成果的多个来源不重复计数；多机构/多领域计数规则可见。 |
| FR11-S04 | 机构归属优先采用成果发生时机构，缺失时计入未知而非当前机构。 |
| FR11-S05 | 真实、模拟和混合数据可区分；默认不得用模拟数据形成现实排名结论。 |
| FR11-S06 | 无结果、样本不足和统计更新中均提供明确反馈，固定样例可人工复核。 |

### 参与者与流程

- **参与者：** 访客；**前置条件：** 存在满足统计条件的已生效数据。
- **主流程：** 选择统计主题/条件→系统显示口径→按去重实体聚合→返回分布或排名→用户调整筛选→查看构成结果的明细范围。
- **异常流程：** 无数据时显示空结果及条件；统计数据正在更新时显示版本/更新时间；口径缺失时不得发布无解释排名。
- **权限/规则：** BR-12～BR-14、BR-16、BR-17；统计不构成学术质量评价。

### 验收条件

- **AC-FR11-S01-01：** Given 固定样例集，When 查看类型分布，Then 各类型计数与按规则手工计算一致且显示口径。
- **AC-FR11-S03-01：** Given 一个成果有两个来源，When 统计总量，Then 只计一个成果实体。
- **AC-FR11-S04-01：** Given 学者当前机构与成果发生时机构不同，When 统计机构排名，Then 成果按发生时机构计入或标未知。
- **AC-FR11-S05-01：** Given 数据含模拟记录，When 查看现实机构排名，Then 模拟数据被排除或结果显式标明仅为演示。

## FR12 基础专家合作关系网络

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR12-S01 | 以公开学者为节点、共同论文关系为边展示基础合作网络。 |
| FR12-S02 | 每条边可查看构成关系的共同论文证据。 |
| FR12-S03 | 关系强度若采用共同论文数，应显示定义并按去重论文计数。 |
| FR12-S04 | 合作边按无向关系处理，同一论文/来源不得重复增加强度。 |
| FR12-S05 | 无合作记录的学者可显示为空网络；规模过大时提示收窄范围。 |
| FR12-S06 | 节点可进入学者门户，论文证据可进入成果详情。 |

### 参与者与流程

- **参与者：** 访客；**前置条件：** 已生效且公开的论文作者关系可用。
- **主流程：** 选择学者/范围→系统构建去重网络→展示节点、边和强度说明→用户选择边查看论文证据→导航到门户或详情。
- **异常流程：** 学者无合作时显示无关系；网络超限时要求缩小范围；关系证据不可公开时不形成公开边。
- **权限/规则：** BR-09、BR-12、BR-15～BR-17；专利、项目、获奖不作为本期基础合作边证据。

### 验收条件

- **AC-FR12-S01-01：** Given 甲乙共同署名论文 P，When 查看网络，Then 存在甲乙边且可追溯到 P。
- **AC-FR12-S03-01：** Given P 被两个来源重复收录，When 计算强度，Then 共同论文数只增加一次。
- **AC-FR12-S05-01：** Given 学者无共同论文，When 查看其网络，Then 明确提示无合作关系而不是查询失败。

## FR13 领域热点分析

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR13-S01 | 用户可选择领域和时间窗口查看关键词/主题等约定热点指标。 |
| FR13-S02 | 结果展示指标定义、数据范围、时间范围、更新时间和排序规则。 |
| FR13-S03 | 同义词、大小写和空白按已声明规则归一；原始词仍可追溯。 |
| FR13-S04 | 展示热点排名或趋势，并明确并列、无数据和样本不足处理。 |
| FR13-S05 | 不把关键词频次、主题热度或趋势解释为研究质量或预测事实。 |

### 参与者与流程

- **参与者：** 访客；**前置条件：** 所选范围内存在可统计的公开成果和指标字段。
- **主流程：** 选择领域/窗口→系统校验范围→按规则聚合→显示热点、趋势和口径→用户查看构成范围。
- **异常流程：** 时间范围无效时拒绝；数据不足时显示不足说明，不使用随机补齐；更新失败时保留上次有效版本并标明时间。
- **权限/规则：** BR-12、BR-14、BR-16、BR-17。

### 验收条件

- **AC-FR13-S01-01：** Given 固定领域样例，When 选择 2024～2026，Then 结果仅使用该领域和窗口内数据。
- **AC-FR13-S03-01：** Given “AI”和“ai”按规则等价，When 汇总，Then 合并计数且可追溯原始表达。
- **AC-FR13-S05-01：** Given 热点排名已生成，When 展示，Then 页面明确说明指标不代表学术质量。

## FR14 管理后台与审计

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| FR14-S01 | 管理员在统一入口查看采集任务、异常数据、待核验关系、认领和成果变更队列。 |
| FR14-S02 | 队列支持按类型、状态、来源和时间筛选，并进入对应处理流程。 |
| FR14-S03 | 管理员可维护分类、账号状态及必要的数据源登记信息。 |
| FR14-S04 | 关键操作要求填写原因，成功或失败均给出明确结果。 |
| FR14-S05 | 审计记录可按操作者、对象、操作类型和时间查询，并展示关键前后值。 |
| FR14-S06 | 非管理员和无对应权限的管理员操作被拒绝。 |

### 参与者与流程

- **参与者：** 管理员；**前置条件：** 已登录且具备对应管理权限。
- **主流程：** 打开工作台→查看待办摘要→筛选并打开对象→查看证据/状态→执行允许的处理→系统校验并更新→记录审计→返回结果。
- **异常流程：** 对象已被处理时提示最新状态；权限不足、版本冲突或规则校验失败时不改变业务数据并记录失败摘要。
- **权限/规则：** BR-01、BR-03～BR-05、BR-18、BR-19；审计记录本身不是普通用户可见内容。

### 验收条件

- **AC-FR14-S01-01：** Given 各类待办均存在，When 管理员进入后台，Then 可分别定位采集、异常、认领、变更和关系核验队列。
- **AC-FR14-S04-01：** Given 管理员驳回申请，When 未填写原因，Then 系统拒绝提交；填写后成功并产生审计记录。
- **AC-FR14-S05-01：** Given 一项合并已完成，When 按对象查询审计，Then 可看到操作者、时间、原因和关键前后值。
- **AC-FR14-S06-01：** Given 普通用户直接访问管理操作，When 提交请求，Then 被拒绝且业务数据不变。

## IN01 合作关系探索

### 子需求

| 编号 | 可观察能力 |
| --- | --- |
| IN01-S01 | 用户可按研究领域筛选合作网络，筛选口径可见。 |
| IN01-S02 | 用户可按机构筛选网络，机构归属口径与 FR11 一致。 |
| IN01-S03 | 用户可选择两名已消歧学者查询当前范围内的最短合作路径。 |
| IN01-S04 | 路径每一跳展示共同论文证据，可导航到论文详情。 |
| IN01-S05 | 无路径、节点不存在、节点不可公开和范围过窄分别反馈。 |
| IN01-S06 | 存在多条等长最短路径时采用确定规则展示，并说明结果范围。 |
| IN01-S07 | IN01 不成为基础合作网络、检索或门户的前置条件。 |

### 参与者与流程

- **参与者：** 访客；**前置条件：** 两名目标学者可公开且身份已经区分，合作数据已生效。
- **主流程：** 选择领域/机构范围→选择起点与终点学者→系统在筛选后的共同论文图中查询最短路径→显示学者序列和逐跳论文证据→用户查看门户或论文详情。
- **备选流程：** 多条等长路径按确定顺序展示有限条数；用户可调整筛选重新查询。
- **异常流程：** 无路径时明确提示；起终点相同返回零跳路径说明；节点被合并/限制时提示重新选择；不得用无共同论文的任意成果连接路径。
- **权限/规则：** BR-13、BR-15～BR-17、BR-20。

### 验收条件

- **AC-IN01-S03-01：** Given 甲—乙—丙是当前范围内最短路径，When 查询甲到丙，Then 返回两跳路径且每一跳有共同论文。
- **AC-IN01-S04-01：** Given 路径已返回，When 用户展开任一边，Then 可查看支撑该边的去重论文并进入详情。
- **AC-IN01-S05-01：** Given 两学者在筛选范围内无连通路径，When 查询，Then 明确提示无路径而非系统错误。
- **AC-IN01-S07-01：** Given IN01 暂不可用，When 用户执行普通检索或查看基础合作网络，Then 基础功能仍可正常使用。
