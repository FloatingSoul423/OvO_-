> 状态：本组初稿，待组内评审与共同基线确认<br>

## 1. 文档目的与范围

本文将需求基线细化为可开发、可测试的外部可观察行为。本版覆盖功能需求、创新需求、非功能需求、权限与业务规则、验收条件和追踪关系；不规定技术栈、数据库表、API、服务拆分或部署方案。Optional 需求不属于本版基础验收范围。

## 2. 系统边界

平台聚合论文、专利、科研项目和获奖四类成果元数据，提供检索、详情、学者门户、认领与维护、数据采集治理、统计分析和管理审核。平台不提供论文投稿、审稿出版、全文托管、付费下载、成果交易、社交私信或学术质量认证。

## 3. 参与者

| 参与者 | 权限边界 |
| --- | --- |
| 访客 | 无需登录访问公开检索、成果详情、学者门户和公开统计。 |
| 登录用户 | 管理本人账号，提交并查看本人认领申请。 |
| 门户管理者 | 仅对已授权的具体学者门户提交维护、成果确认、补录和纠错。 |
| 管理员 | 管理采集任务、数据治理、审核队列、分类、账号和审计。 |
| 外部数据来源 | 向平台提供公开或获准使用的元数据/文件，不具有人类账号权限。 |

账号、学者档案、门户管理授权、成果关系和审核申请是不同对象；任何一个对象的状态不得自动代替另一个对象的状态。

## 5. 公共业务规则

| 编号 | 规则 |
| --- | --- |
| BR-01 | 访客只能访问公开信息；审核材料、待审版本和内部治理证据不公开。 |
| BR-02 | 用户账号与学者档案分离；档案可在无对应账号时存在。 |
| BR-03 | 门户管理权限是对象级授权，只允许管理审核通过的目标门户。 |
| BR-04 | 已有管理人的冲突认领不自动转移权限，须进入人工核验。 |
| BR-05 | 待审修改不得覆盖当前公开版本；仅审核通过的变更对外生效。 |
| BR-06 | 解除某学者与成果的关系不得删除全局成果或其他参与者关系。 |
| BR-07 | 每条成果保留来源、来源标识、采集/导入时间和更新时间；跨源合并保留全部出处。 |
| BR-08 | 稳定标识归一后优先用于成果去重；仅标题相似不得直接合并。 |
| BR-09 | 姓名相同不足以合并学者；证据不足时只生成候选并转人工核验。 |
| BR-10 | 自动更新不得静默覆盖已人工确认或审核通过的业务结果。 |
| BR-11 | 采集任务至少区分待执行、运行中、成功、失败、重试、已停止；重试不得重复入库。 |
| BR-12 | 全平台成果总量按去重后的成果实体计数；来源记录不重复增加总量。 |
| BR-13 | 机构统计优先采用成果发生时的机构；缺失时标记未知，不静默使用当前机构。 |
| BR-14 | 统计与热点必须披露数据范围、时间范围、筛选条件和计数口径。 |
| BR-15 | 合作网络的边必须由共同论文支撑；路径每一跳均可追溯到论文证据。 |
| BR-16 | 关键词频次、热点、合作强度和机构排名不代表学术质量评价。 |
| BR-17 | 真实、模拟和混合数据必须显式标识；模拟数据不得用于描述真实世界排名或合作结论。 |
| BR-18 | 关键审核、合并、拆分、权限授予和重要修改须记录操作者、时间、前后值和原因。 |
| BR-19 | 门户状态、认领申请状态、成果关系状态、成果变更状态和发表状态分别表达。 |
| BR-20 | O01/O02 等 Optional 不得成为 FR01～FR16 或 IN01 的前置条件。 |
